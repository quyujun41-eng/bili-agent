职位描述

负责大模型应用产品的设计与落地，包括但不限于：

• 基于 RAG 架构搭建知识库问答系统，优化检索精度与响应速度

• 使用 Function Call / Tool Use 构建 AI Agent，实现复杂业务流程自动化

• 对接 Claude、GPT-4 等主流大模型 API，进行 Prompt 工程优化

• 设计并实现 Hybrid 检索方案（BM25 + 向量检索 + RRF 融合）

• 参与 MCP Server 开发，为内部 AI 工具链提供标准化接口


任职要求：

• 熟悉 Python，有 FastAPI / Flask 开发经验

• 有 RAG 系统实际落地经验，了解向量数据库（Qdrant/Chroma）

• 理解 LLM 工作原理，有 Prompt Engineering 实践经验

• 有 Agent / Function Call 开发经验者优先
